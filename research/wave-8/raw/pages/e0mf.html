Double pistol squat

  • strength

Skill Tree

Muscles

  • Gluteus maximus
  • Semitendinosus
  • Semimembranosus
  • Biceps femoris (long)
  • Rectus femoris
  • Vastus medialis
  • Vastus intermedius
  • Vastus lateralis

Technique

  1. Partners stand facing each other, gripping each other's wrists.
  2. Both lift the same leg at the same time (both left, then both right).
  3. Leaning back to counterbalance each other's weight, both perform a pistol squat by bending the planted leg.
  4. Switch legs to work both sides evenly.

Form tips

  1. Work with each other rather than against each other, using the partner as leverage and avoiding pulling one person up (which can happen if there is a difference in leg strength).
